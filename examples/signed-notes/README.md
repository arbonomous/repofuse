advertising with an honest fixed one-hour lifetime. Original model outputs

Validated on Linux with bubblewrap, not native Mac. Notes are in memory;
restart clears notes and rotates signing secret. Links last one hour.

## Safe reproduction

1. Review every source file, vendor notice and serving.json. Verify the
   shipped source-manifest hashes. Do not install or run upstream setup hooks.
2. Use the RepoFuse whole-tree review workflow to create your OWN approval
   for these exact bytes. No approval is bundled or implied by the manifest.
3. Run RepoFuse's isolated verification with that approval. Do not import
   generated code or run wsgiref directly on the bare host. Missing bubblewrap
   is a blocker, not a reason to disable containment.
4. Use the reviewed Studio serving path with its full safety/run gates. It
   returns a parent-owned local 127.0.0.1 origin and never a public URL. A fresh
   source checkout does not contain private run state or acknowledgments.

This package contains source for inspection/reproduction through the gated
workflow. It does not include a one-click imported run, credentials, a paid
model grant, or permission to bypass independent review. No paid call is
needed to inspect or verify already-generated source.
